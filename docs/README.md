## 文档维护规范

1. **版本号**：采用语义化版本 `vX.Y.Z`（主版本.次版本.修订号）
2. **变更流程**：任何需求或技术栈变更须经过评审，并在对应文档的「更新记录」中登记
3. **阶段门禁**：每个开发阶段启动前，确认三份文档均为最新版本
